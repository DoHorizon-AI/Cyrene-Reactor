# Deployment evidence / 部署证据

These documents separate local contract checks, historical protected-runtime
observations, and unperformed hosted or remote-machine acceptance. Dependency
records contain package metadata and file digests only. Raw execution receipts,
environment identifiers, and credentials stay in the operator's private evidence
directory and are intentionally excluded from this source tree.
